# Python Console-Based Calculator

My first Python programming project.

## Project Description
A simple menu-driven calculator built using Python.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Repeated calculations using while loop
- Division by zero handling
- Exit option

## Concepts Used
- Python Functions
- While Loop
- If, Elif, Else
- Break Statement
- Arithmetic Operators

## Technology
- Python 3

## How to Run
1. Download `calculator.py`.
2. Open Command Prompt.
3. Navigate to the project folder.
4. Run:

```bash
python calculator.py
```
